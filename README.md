## Installation

1. zs_analytics requires Docker to be installed. Follow these instructions depending on the platform you use:

    - [macOS](https://docs.docker.com/desktop/install/mac-install/)
    - [Linux](https://docs.docker.com/engine/install/)
    - [Windows](https://docs.docker.com/desktop/install/windows-install/)

2. Clone repository:

        git clone https://github.com/zergos1987/zs_analytics && cd zs_analytics

3. Running containers (dev mode):
    dev mode

        docker compose up
        
    prod mode

        docker compose up
